Scope

- Update translation_en for every row to match these guidelines.

Input Columns (TSV)

Task (core principles)
- Provide a short English gloss that captures the main verbal meaning in context.
- Use the example sentences to disambiguate tense, aspect, voice, valency, and sense when necessary.
- Keep the gloss brief: 1–2 words for simple senses (e.g., “go”, “say”), or a compact clause for finite forms (e.g., “I go”, “he/she/it goes”), or a compact phrase for multi‑sense verbs separated by semicolons (max three senses).
- Lowercase the gloss unless capitalization is required (rare: proper names in examples are not part of the gloss).

Finite Forms (person‑aware clauses)
- Write a short English clause beginning with the implied subject:
  - 1sg → “I …”
  - 2sg → “you …”
  - 3sg → “he/she/it …”
  - 1pl → “we …”
  - 2pl → “you (plural) …”
  - 3pl → “they …”
- Conjugate the English verb appropriately:
  - Present: 3sg takes -s/-es (“he/she/it goes; says; does”). Others base form (“I go”).
  - Imperfect: use simple past (“I went; I said”), optionally include continuous if examples demand it, but prefer simple past.
  - Passato remoto (Tense=Past on simple forms like disse/andò): simple past with perfective nuance (“he/she/it went; he/she/it said”). Add completion nuance only if examples force it.
  - Future: “will …” (“I will go”). Use probability/epistemic reading only if examples clearly indicate it; prefer literal future.
  - Conditional: “would …” (“I would go”).
  - Subjunctive (Mood=Sub): keep concise and literal: “that I …; that you …; that he/she/it …; that we …; that you (plural) …; that they …” If examples clearly use potential/desired reading, you may use “may/might …” but keep it short and parallel across persons.
  - Imperative: “(you) …!”; “(you (plural)) …!”; “let’s …!” For negative imperative, “don’t …!” Keep punctuation minimal; no exclamation mark required.

Non‑Finite Forms (neutral forms)
- Infinitive (VerbForm=Inf): “to …” (“to go”, “to say”, “to do”).
- Gerund (VerbForm=Ger): “…ing” (“going”, “saying”, “doing”).
- Participle (VerbForm=Part): English past participle where applicable (“gone”, “said”, “done”; for regular verbs “-ed” form “talked”). If examples clearly require passive voice, still keep the entry as the bare participle (“done”, not “been done”).

Cliticized and Reflexive Forms (important)
- Reflexive (mi/ti/si/ci/vi + verb, including lemma with “-si” or forms like “lavarsi”, “chiamarsi”):
  - Infinitive: “to … oneself” (“to wash oneself”; where English uses a non‑reflexive idiom, prefer the standard concise counterpart: “to get up”, “to sit down”).
  - Gerund: “…ing oneself” (“washing oneself”) where natural; often just “…ing” is enough if examples show idiomatic non‑reflexive English; choose the most concise natural English.
  - Participle: past participle with reflexive nuance only if needed; usually the plain participle (“washed”).
  - Finite forms: include the appropriate object if it’s overtly reflexive in the examples: “I wash myself”, “he/she/it calls himself/herself/itself”, but prefer the natural English rendering (“I get up”, “he sits down”).
- Enclitic object pronouns on the verb (lo/la/li/le/ne; gli/le; combined forms like glielo): integrate objects directly in the English gloss rather than using placeholders:
  - Infinitive examples: “dirlo” → “to say it”; “darglielo” → “to give it to him”; “portarmelo” → “to bring it to me”.
  - Gerund examples: “dicendolo” → “saying it”; “facendoglielo” → “doing it for him”.
  - Participle examples: “detto” stays “said”; if clitics are bound in the token (rare for participles), prefer concise “said it”, but only if the token explicitly includes them.
  - Imperative enclitics: “dimmi” → “tell me”; “dimmelo” → “tell me it” (prefer “tell me it” over “tell it to me” to keep it compact unless examples force the double preposition).
  - Combined clitics: order in English “it/them to him/her”, “it/them to you”, “of it/of them” for “ne”: glielo → “it to him”; glieli → “them to him”; gliene → “of it to him”. Keep to a short, readable English phrase.

Cut‑off Infinitives (aiutar, andar, dar, veder …)

- If the cut‑off infinitive appears alone (no clitic next to it), gloss it as the plain infinitive: “aiutar” → “to help”; “andar” → “to go”; “dar” → “to give”.
- Apply the same rule with reflexive/combined clitics when they are split across tokens: “andar si”/“andar se ne” → prefer the most concise natural English guided by examples (e.g., “to go away”).
