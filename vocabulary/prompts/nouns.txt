You are filling the English glosses for Italian nouns in TSV files. For each row, write a concise, learning‑friendly translation into the column translation_en. Preserve the TSV structure and all other columns exactly as they are.

Scope
- Process only TSVs under NOUN (nouns). Each file contains rows for a specific lemma with inflected forms.
- Update the translation_en cell for every row (fill if empty or rewrite to match guidelines).

Input Columns (TSV)
- text, lemma, pos, xpos, deprel, feats, sentence_1_it, sentence_1_en, sentence_2_it, sentence_2_en, sentence_3_it, sentence_3_en, translation_en, plus other numeric/hash columns.

Task
- Produce a brief English translation (gloss) for the Italian noun in text.
- Use the sentences (it/en) to select the correct sense(s) and to disambiguate when a word is polysemous (e.g., storia = story; history).
- Keep the output short but descriptive enough for learners to grasp the meaning.

Style and Formatting (must follow exactly)
- Write lowercase headwords; no initial capitalization unless the gloss is a proper name (rare for common nouns).
- Do not add articles in English (“a”, “an”, “the”). Use bare nouns: house, friend, water, books.
- Plural forms should be glossed in plural: case → houses; amici → friends.
- Separate multiple senses with semicolons: sense1; sense2; sense3
- Add morphological/usage notes in parentheses at the end, when helpful. Gender notes are included only when the lemma group has both masculine and feminine variants; use (masculine) or (feminine). Never mark “singular”. Add “(plural)” only when the English gloss does not already make plurality obvious. Other notes (e.g., proper name) should stay concise.
- Keep punctuation minimal: no trailing period. Use ASCII apostrophes (') in any Italian forms shown in examples; do not smart‑quote. If a form uses an apostrophe before a vowel, annotate as “(before a vowel)” when a note is warranted.
- Do not quote the gloss. No brackets. Only use parentheses for the notes described above.
- Be consistent across a lemma’s paradigm (same set/order of senses and same note patterns where applicable).

Sense Guidelines (use sentences + lemma semantics)
- Prefer the core dictionary sense unless the example sentences clearly demand a different one.
- If two core senses are both common and supported by sentences, include both separated by a semicolon (e.g., storia → story; history).
- Avoid rare, domain‑specific senses unless sentences make them unambiguous.
- For human roles that differ by gender in Italian, keep the same English base gloss and add the gender note: amico/amica → friend (masculine/feminine …).
- For mass nouns (e.g., acqua), just use a bare noun unless context demands additional clarification.
- For nouns that can denote a group (e.g., gente), keep the gloss simple unless further detail is essential.

Morphology Notes (exact phrasing)
- Gender notes: include only when the lemma group has both masculine and feminine variants; use “masculine” or “feminine”. If a noun is only masculine or only feminine without a counterpart (e.g., cibo), omit the gender note.
- Number notes: never mark “singular”. Add “(plural)” only when the English gloss does not already make plurality obvious.

Decision Rules
- Select senses supported by the example sentences. If multiple are clearly suggested, include both, separated by a semicolon.
- If sentences are neutral or generic, use the core dictionary senses for the lemma.
- Keep to 1–3 short senses unless a fourth is clearly justified by examples.
- Spell‑check the glosses; avoid typos. Use simple learner‑friendly words.

Output Constraints
- Modify only the translation_en field for each row; do not alter any other column values or order.
- Do not insert or remove columns or tabs. Each line must remain a valid TSV row.
- No line breaks inside the translation cell. No trailing spaces.
